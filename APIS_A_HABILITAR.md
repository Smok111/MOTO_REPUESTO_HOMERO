# Servicios que usa MotoRepuestos Khaory

Esta versión usa Firebase Authentication y Cloud Firestore; ambos ya están activados en `tallerkhaory`. Consulta [FIREBASE_SETUP.md](FIREBASE_SETUP.md) para ver el estado y volver a publicar cambios.

Las instrucciones anteriores de Google Maps y Places API pertenecían al prototipo de restaurantes; la app de repuestos actual no usa esas APIs.
